# library
# Ψηφιακή Βιβλιοθήκη Διπλωματικών — πρώτη έκδοση

## Περιεχόμενα
- `index.html`: η δημόσια ιστοσελίδα αναζήτησης.
- `catalog.csv`: ο κατάλογος που διαβάζει η ιστοσελίδα.
- `Theses_Catalog.xlsx`: πρότυπο Excel για τη γραμματεία.
- `README.txt`: οδηγίες εγκατάστασης και ενημέρωσης.

## Σημαντικό για την ασφάλεια και τη δημοσίευση
1. Δημοσιεύετε μόνο εργασίες για τις οποίες υπάρχει κατάλληλη άδεια δημόσιας διάθεσης.
2. Μην ανεβάζετε τα ίδια τα PDF στο δημόσιο αποθετήριο GitHub. Στο `catalog.csv` μπαίνουν μόνο σύνδεσμοι κοινής χρήσης OneDrive με δικαίωμα προβολής.
3. Κάθε σύνδεσμος OneDrive τύπου «Οποιοσδήποτε διαθέτει τη σύνδεση» μπορεί να προωθηθεί και σε τρίτους. Ελέγξτε τις ρυθμίσεις πρόσβασης και δοκιμάστε κάθε PDF σε ιδιωτικό παράθυρο browser.
4. Το `catalog.csv` είναι δημόσιο μαζί με την ιστοσελίδα. Περιλαμβάνει τίτλους, συγγραφείς, περιλήψεις και λέξεις-κλειδιά. Μη συμπεριλάβετε προσωπικά/εμπιστευτικά στοιχεία.

## Αρχική εγκατάσταση με GitHub Pages
1. Δημιουργήστε λογαριασμό στο GitHub, αν δεν έχετε.
2. Δημιουργήστε νέο repository με όνομα π.χ. `thesis-library` και ορίστε το ως Public.
3. Ανεβάστε στο repository τα `index.html` και `catalog.csv` (όχι τα PDF και όχι το Excel με εσωτερικές σημειώσεις).
4. Στο repository: Settings → Pages → Build and deployment → Deploy from a branch → `main` και `/ (root)` → Save.
5. Περιμένετε να εμφανιστεί η δημόσια διεύθυνση Pages στις ρυθμίσεις. Δοκιμάστε την από ιδιωτικό παράθυρο.

## Προσθήκη διπλωματικής
1. Ανεβάστε το PDF στον κατάλληλο φάκελο OneDrive.
2. Δημιουργήστε σύνδεσμο κοινής χρήσης με δικαίωμα προβολής. Αν απαιτείται δημόσια πρόσβαση χωρίς σύνδεση, επιλέξτε «Οποιοσδήποτε διαθέτει τη σύνδεση» μόνο εφόσον επιτρέπεται από την πολιτική του ιδρύματος και τα δικαιώματα του συγγραφέα.
3. Δοκιμάστε τον σύνδεσμο από ιδιωτικό παράθυρο.
4. Συμπληρώστε μία νέα γραμμή στο `Theses_Catalog.xlsx`.
5. Αποθηκεύστε/εξαγάγετε το φύλλο ως CSV UTF-8 με όνομα `catalog.csv` και αντικαταστήστε το παλιό αρχείο στο GitHub. Διατηρήστε ακριβώς τις κεφαλίδες:
   `ID,Title,Author,Year,Supervisor,Category,Keywords,Abstract,PDF_Link`
6. Ελέγξτε την ιστοσελίδα και το άνοιγμα του PDF.

## Πεδία
- `ID`: μοναδικός κωδικός, π.χ. TH-0001.
- `Title`: πλήρης τίτλος.
- `Author`: ονοματεπώνυμο συγγραφέα.
- `Year`: έτος κατάθεσης.
- `Supervisor`: επιβλέπων.
- `Category`: μία κύρια θεματική.
- `Keywords`: λέξεις-κλειδιά χωρισμένες με ελληνικό ερωτηματικό ή `;`.
- `Abstract`: περίληψη (προαιρετική).
- `PDF_Link`: σύνδεσμος OneDrive.

## Περιορισμοί της πρώτης έκδοσης
- Η αναζήτηση γίνεται στον δημόσιο κατάλογο CSV, όχι μέσα στο πλήρες κείμενο των PDF.
- Η ενημέρωση γίνεται με αντικατάσταση του CSV στο GitHub.
- Η ιστοσελίδα δεν έχει σύστημα σύνδεσης ή διαχείρισης χρηστών.
- Η διαθεσιμότητα συνδέσμων OneDrive εξαρτάται από τις ρυθμίσεις και τους περιορισμούς του λογαριασμού Microsoft.
